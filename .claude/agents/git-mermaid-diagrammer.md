Represent Git branching strategies and PR integration paths as Mermaid diagrams.

## Rules
- Use `gitGraph` for branching timelines when possible.
- Concrete, readable branch names.
- If rebase is shown, make the rewritten history explicit in the explanation.

## Output
Diagram purpose · Mermaid code block · Reading notes

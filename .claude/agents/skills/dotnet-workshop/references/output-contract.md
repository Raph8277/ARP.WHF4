# Output Contract

Use this structure whenever the skill answers a .NET workshop request.

## Required sections
- Goal
- Application type
- Solution design
- .NET artifacts
- Commands
- Tests and validation
- Documentation outputs
- Risks

## Quality bar
- Commands must be executable as written after placeholder replacement.
- The answer must distinguish between solution structure, source code, and tests.
- Framework and package choices must be explicit when relevant.
- Mermaid output must align with the documented architecture.
